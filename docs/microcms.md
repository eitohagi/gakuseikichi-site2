# microCMS のAPI設計

**エンドポイント名とフィールドIDは、この表のとおりに作ってください。** サイトはこの名前で読みに行きます。
表示名は自由に変えてかまいません。

## 作る順番

1. `settings`（オブジェクト形式）
2. `members`（リスト形式）。ほかのAPIがメンバーを参照するので先に作る
3. `articles` `communities` `products` `demos` `applications`（すべてリスト形式）

繰り返しフィールドに使うカスタムフィールド（`forecastStep`、`spec`、`cycleStep`）は、そのAPIの設定画面で先に作ります。

## APIキー

| キー | 環境変数 | 許可する権限 |
|---|---|---|
| 読み込み用 | `MICROCMS_API_KEY` | `settings` `members` `articles` `communities` `products` `demos` の GET。`articles` だけ「下書きコンテンツの全取得」も許可（プレビュー用） |
| 書き込み用 | `MICROCMS_WRITE_KEY` | `applications` の POST だけ |

> **`applications` には、読み込み用キーの権限を一切つけないでください。**
> 申し込んだ人の名前とメールアドレスが入るため、管理画面でしか見られないようにします。

## `settings`（団体の基本情報）オブジェクト形式

空の項目は、サイト側の既定値（`src/config/site.ts`）が使われます。

| フィールドID | 表示名 | 種類 | メモ |
|---|---|---|---|
| name | 団体名 | テキストフィールド | 例：学生基地 |
| nameEn | 団体名（ローマ字） | テキストフィールド | トップとフッターの大きなロゴ。例：Gakusei Kichi |
| mission | ひとこと | テキストフィールド | 例：未来を予測し、遠い未来の準備をしながら、近い未来を実現する。 |
| lede | トップの見出し | テキストエリア | 改行がそのまま反映される |
| description | 説明文 | テキストエリア | 検索結果とSNSに出る。120文字程度 |
| cycle | 1週間の回し方 | 繰り返し（カスタム `cycleStep`） | 順番どおりに表示 |
| email | 連絡先メール | テキストフィールド | 空なら表示しない |
| instagram | Instagram | テキストフィールド | アカウント名だけ（@なしでよい） |
| youtube | YouTube | テキストフィールド | チャンネルのURL |
| x | X | テキストフィールド | アカウント名だけ |
| ogImage | SNS用画像 | 画像 | 1200×630。空なら同梱の画像 |
| legal | 特定商取引法に基づく表記 | リッチエディタ | 販売を始める前に必ず書く |
| privacy | 個人情報の扱い | リッチエディタ | 空なら同梱の文面 |

カスタムフィールド `cycleStep`：`title`（テキスト）、`body`（テキストエリア）

## `members`（メンバー）

| フィールドID | 表示名 | 種類 | 必須 | メモ |
|---|---|---|---|---|
| name | 名前 | テキストフィールド | ○ | 本名でなくてもよい |
| role | 役職 | セレクトフィールド | ○ | 選択肢：代表 / 副代表 / メンバー。サイトではこの順に並ぶ |
| field | 分野 | テキストフィールド | | 例：Food × Town |
| color | 色 | セレクトフィールド | ○ | 選択肢：朱 / 緑青 / 漆 / 藍 / 紫 / 桃 / 山吹 |
| photo | 上半身の写真 | 画像 | | あれば写真の色でモザイク肖像を作る。顔が上のほうにある縦長の写真がよい |
| project | プロジェクト名 | テキストフィールド | ○ | |
| description | プロジェクト説明 | テキストエリア | | 1〜2文 |
| forecastClaim | 未来予報 | テキストフィールド | | 例：直せるものしか、選ばれなくなる。 |
| forecastSteps | 予報の確率 | 繰り返し（カスタム `forecastStep`） | | 3つがきれいに並ぶ（最大4つ） |
| forecastAction | 今日の行動 | テキストフィールド | | 読んだ人が今日できること |

カスタムフィールド `forecastStep`：`year`（数字。年）、`probability`（数字。0〜100）

> コンテンツIDがメンバーページのURLになります（`/members/<コンテンツID>/`）。
> 作るときにコンテンツIDを `eito` のような英字にしておくと、URLがきれいになります。

## `articles`（記事）

| フィールドID | 表示名 | 種類 | 必須 | メモ |
|---|---|---|---|---|
| title | タイトル | テキストフィールド | ○ | |
| author | 書いた人 | コンテンツ参照（`members`） | ○ | |
| tags | タグ | セレクトフィールド（複数選択） | | 例：活動報告 / 研究 / 制作記録 / 未来予報 / イベント |
| cover | カバー画像 | 画像 | | 横長（16:9）。空なら書いた人の色で和柄を描く |
| excerpt | 要約 | テキストエリア | | 一覧と検索結果に出る1〜2文 |
| body | 本文 | リッチエディタ | ○ | 見出し、画像、リンク、YouTube埋め込みが使える |
| forecastClaim | この記事時点の予報 | テキストフィールド | | 空なら書いた人の現在の予報を表示 |
| forecastSteps | 予報の確率 | 繰り返し（`forecastStep`） | | |
| forecastAction | 今日の行動 | テキストフィールド | | |

API設定の「画面プレビュー」に次のURLを登録します（`<サイト>` は本番のURL）。

```
https://<サイト>/preview?id={CONTENT_ID}&draftKey={DRAFT_KEY}
```

## `communities`（コミュニティ）

| フィールドID | 表示名 | 種類 | 必須 |
|---|---|---|---|
| name | 名前 | テキストフィールド | ○ |
| type | 種類 | セレクトフィールド（つくる / 話す / 学ぶ） | ○ |
| description | 説明 | テキストエリア | |
| frequency | 頻度 | テキストフィールド（例：毎週金） | |
| memberCount | 参加者数 | 数字 | |
| tags | タグ | テキストフィールド（読点かカンマ区切り） | |

## `products`（プロダクト）

| フィールドID | 表示名 | 種類 | 必須 | メモ |
|---|---|---|---|---|
| name | 商品名 | テキストフィールド | ○ | |
| maker | 出品者 | コンテンツ参照（`members`） | ○ | |
| price | 価格（円、税込） | 数字 | ○ | |
| category | カテゴリ | テキストフィールド | | |
| image | 写真 | 画像 | | 縦長（4:5）。空なら出品者の色で和柄を描く |
| paymentLink | 支払いリンク | テキストフィールド | | Stripe の支払いリンク（`https://buy.stripe.com/...`）。空なら「準備中」 |
| soldOut | 売り切れ | 真偽値 | | |

## `demos`（3Dデモ）

| フィールドID | 表示名 | 種類 | 必須 | メモ |
|---|---|---|---|---|
| title | 名前 | テキストフィールド | ○ | |
| maker | 作った人 | コンテンツ参照（`members`） | | |
| description | 説明 | テキストエリア | | |
| specs | 仕様 | 繰り返し（カスタム `spec`） | | |
| model | 3Dモデル | ファイル | | **.glb 形式**。大きさと向きはサイト側でそろえる |
| preset | 見本モデル | セレクトフィールド（器 / センサー / ワゴン） | | モデルがないときに使う |

カスタムフィールド `spec`：`label`（テキスト）、`value`（テキスト）

> ファイルフィールドが使えるかどうかは microCMS のプランによって異なります。

## `applications`（申し込み）サイトから自動で入る

| フィールドID | 表示名 | 種類 | メモ |
|---|---|---|---|
| kind | 種類 | セレクトフィールド（参加希望 / コミュニティ申し込み） | |
| name | 名前 | テキストフィールド | |
| email | メール | テキストフィールド | |
| like | すきなこと | テキストフィールド | 参加希望のみ |
| way | 関わり方 | テキストフィールド | 参加希望のみ |
| community | コミュニティ | テキストフィールド | |
| message | ひとこと | テキストエリア | |
| status | 対応状況 | セレクトフィールド（未対応 / 連絡済み / 完了） | 運営が手で更新する |

申し込みは**下書き**として保存され、公開されることはありません。

## Webhook

`settings` `members` `articles` `communities` `products` `demos` の6つに、Vercel の Deploy Hook のURLを登録します。
発火のタイミングは「コンテンツの公開・更新・削除」です。`applications` には登録しません（申し込みのたびにサイトを作り直す必要はないため）。
